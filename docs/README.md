# Tài liệu dự án

Bộ tài liệu cho frontend **luồng onboarding B2B** khi mở rộng nền tảng Recognition & Rewards nội bộ thành SaaS (Sperraw).

| File | Nội dung |
| --- | --- |
| [product-context.md](./product-context.md) | Bối cảnh sản phẩm, mục tiêu, phạm vi |
| [onboarding-flow.md](./onboarding-flow.md) | Đăng ký admin, tạo workspace, wizard, homepage |
| [frontend.md](./frontend.md) | Routing, store, cấu trúc code |
| [api.md](./api.md) | Contract mock API (MSW) mà frontend đang gọi |

Đọc theo thứ tự trên. `onboarding-flow.md` và `frontend.md` mô tả **implementation hiện tại**, không phải spec cũ trên một route `/register`.
